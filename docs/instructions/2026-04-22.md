## Structure and clarifying details

Below is an overview of the files and their desired function. If you think there is a better way to structure the files, make a suggestion.

- [main.py](http://main.py):
  - User sets the parameters of the system, data manipulation, simulation, analysis and results
  - Executes all the sub-programs
- load_data.py
  - Loading of the data from files or generate time-data from simulation
  - assign the data to a certain measurement direction, x or y.
  - set which channel is used for which sensor location
  - which sensitivities and constants should be used with each sensor and equation
  - the equations that turn the sensor data into new variables for further processing
- [frf-estimation.py](http://frf-estimation.py)
  - calculation of the FRF based on the variables created in load data.
  - When using simulation, estimating the FRF based on time-data simulation or using the transfer functions of the simulations directly.
- simulate_system.py
  - generation of the transfer function of the system
  - generation of artificial data from a model of a mechanical system
- stability_measurement.py
  - calculation and visualization of the stability of the milling process using a spectrogram
- stability_lobe_diagram.py
  - Calculation of the stability lobe diagram (SLD) based on the transfer function or FRF

## Some details of simulate_system.py

- Transfer functions x/F_x and y/F_y are calculated based on a model
- The parameters of the model are set in the configuration json file.
  - Currently a simple mass-spring-damper model.
- the input and output are set by the user in the json configuration file
- F_x and F_y are then simulated
- x and y are then simulated by calculating the response of x/F_x with F_x as input and y/F_y with F_y as input.
- x and y are then mapped to x_tool and y_tool, and x_spindle and y_spindle. These variables are then used to calculate all the sensor values in all the different configurations. The equations are already listed above. Do not duplicate the equations, but use one file where the equations are coded as a function that can then be used here in the simulation.
